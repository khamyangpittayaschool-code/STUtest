# PROMPT — SENIOR FULL-STACK DEVELOPER

## AI TRAINING MANAGEMENT, GAMIFICATION & ASSIGNMENT SYSTEM

คุณคือ **Senior Full-stack Developer, Software Architect, Database Architect และ UI/UX Designer** มีหน้าที่ออกแบบและพัฒนาระบบ Web Application สำหรับโรงเรียน เพื่อใช้บริหารจัดการกิจกรรมอบรมการประยุกต์ใช้เทคโนโลยีปัญญาประดิษฐ์ (Artificial Intelligence: AI)

ระบบต้องเป็น **Production-ready Web Application** สามารถใช้งานจริงได้ ไม่ใช่เพียง Mockup หรือ Static UI

ระบบต้องรองรับผู้ใช้งานพร้อมกันประมาณ **200 คน** และต้องออกแบบให้สามารถขยายจำนวนผู้ใช้งานในอนาคตได้

# 31. Atomic Transaction

การให้คะแนนต้องเป็น Transaction

```text
BEGIN

ตรวจสอบ Code

Lock Code

ตรวจสอบการใช้ซ้ำ

เพิ่ม Score Transaction

เพิ่ม Individual Score

เพิ่ม Group Score

เปลี่ยน Code เป็น USED

บันทึก Audit Log

COMMIT
```

หากเกิด Error

```text
ROLLBACK
```

ต้องไม่เกิดกรณี

```text
คะแนนเพิ่ม
แต่ Code ยังไม่ถูกบันทึกว่าใช้แล้ว
```

หรือ

```text
Code ถูกใช้
แต่คะแนนไม่เพิ่ม
```

# 69. Acceptance Criteria

ระบบถือว่าสมบูรณ์เมื่อ

### สมาชิก

นักเรียนสมัคร → Login ได้ทันที

### กลุ่ม

นักเรียนสร้างกลุ่ม → นักเรียนคนอื่นเข้ากลุ่มได้

### Activity

Admin สร้าง Activity → นักเรียนเห็น Activity

### Post

Admin/Teacher สร้าง Post → นักเรียนเห็น Post

### Assignment

Admin สร้างงาน → นักเรียนส่งข้อความ/รูป/วิดีโอ/ไฟล์/Link ได้

### Grading

ครูตรวจ → ให้คะแนน → นักเรียนเห็นคะแนน

### Code

Admin สร้าง 1,000 Code → ไม่มี Code ซ้ำ

### Score

นักเรียนกรอก Code → ได้คะแนนถูกต้อง

### Group Score

คะแนนกลุ่มเพิ่มตามกติกา

### Duplicate

กรอกรหัสเดิม → ไม่ได้คะแนนซ้ำ

### Leaderboard

คะแนนเปลี่ยน → อันดับเปลี่ยนแบบ Real-time

### Security

Student ไม่สามารถเพิ่ม/แก้คะแนนของตัวเอง
